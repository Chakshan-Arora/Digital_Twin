# Frontend Layout & Application Shell

## Owner
**Person 1: Frontend & UX Engineer**

## Scope
- `frontend/src/layout/`
- `frontend/src/App.tsx`
- `frontend/src/components/`

## Contract

### Inputs
- Application mode state (`'clearance-lab' | 'body-explorer'`).
- Active `BodyParams` generated by `frontend/src/scanner/` or selected preset.
- Dermatome/nerve selection state from `frontend/src/atlas/` and `frontend/src/nervous/`.
- Medical digital twin clearance & uncertainty data from existing clearance components.

### Outputs
- Mode switching interface and top-level header status bar.
- Unified split / full-screen workstation layouts.
- Shared styling tokens and responsive layouts.
- Preserves existing Clearance Lab UI components (`CaseDetailsCard`, `SliceViewer`, `Viewer3D`, `ClearancePanel`, `UncertaintyPanel`) untouched.
